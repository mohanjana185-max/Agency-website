# 🎨 FORMA — Creative & Digital Agency

A modern and responsive creative agency website built using **HTML, CSS and JavaScript**.

## ✨ Features

* 🎨 Modern creative agency design
* 📱 Fully responsive layout
* 🎥 Video hero section
* ✨ Smooth scroll animations
* 🖱️ Interactive cursor effects
* 💼 Services section
* 📂 Projects / Work section
* 👤 About section
* 📩 Contact section
* 🍔 Responsive mobile navigation

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Fonts

## 📱 Responsive Design

The website is designed to work across:

* 💻 Desktop
* 📱 Mobile
* 📟 Tablet

## 🚀 Project Purpose

This project was created as a **frontend web development practice project** to improve skills in responsive design, animations, UI development and JavaScript interactions.
